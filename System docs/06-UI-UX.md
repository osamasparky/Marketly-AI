# AI Marketing Employee — UI/UX Specification

## 1. Product Personality
Premium, modern, calm, AI-native, business-focused.

Core phrase:
"Your AI Marketing Employee"

The product should feel like a command center, not a generic admin panel.

## 2. Main Navigation
- Dashboard
- Brand Brain
- AI Strategy
- Campaigns
- Content Studio
- Calendar
- Creative Studio
- Publishing
- Analytics
- AI Assistant
- Settings

Agency users also get:
- Clients / Organizations

## 3. Dashboard
Show:
- Today's content
- Published today
- Scheduled content
- Awaiting approval
- Reach
- Engagement
- Leads/clicks where available
- AI insight
- AI recommendation
- Upcoming content
- AI activity timeline

## 4. Onboarding
Use a progressive, conversational wizard:
1. Business
2. What you sell
3. Audience
4. Goals
5. Brand assets
6. Documents
7. Social accounts
8. Brand Brain review
9. Strategy preview
10. Generate first content

Avoid long traditional forms.

## 5. Brand Brain
Sections:
- Overview
- Products
- Services
- Audience
- Brand Voice
- Visual Identity
- Competitors
- Knowledge Documents
- AI Understanding

Show "AI learned this" explanations and allow corrections.

## 6. Content Studio
Layout:
- left: generation controls
- center: content editor
- right: preview/AI checks

Actions:
- Generate
- Regenerate
- Improve Hook
- Shorten
- Make more professional
- Make Egyptian Arabic
- Make Saudi Arabic
- Repurpose
- Create Reel
- Create Visual
- Schedule

## 7. Calendar
Month/week views.
Cards show:
- platform
- format
- status
- campaign
- AI score
- scheduled time

Drag/drop must preserve authorization and rescheduling rules.

## 8. Creative Studio
Tabs:
- Images
- Reels
- Templates
- Brand Assets

Show generation progress and cost-aware warnings for expensive operations.

## 9. Publishing
Show:
- connected accounts
- health
- scheduled queue
- published
- failed
- retry

## 10. Analytics
Top KPIs followed by:
- performance over time
- platform comparison
- content type comparison
- top posts
- weak posts
- AI explanation
- recommendations

## 11. AI Assistant
Chat-like interface with suggested actions:
- Create a campaign
- Generate next week
- Analyze performance
- Repurpose a post
- Create an offer campaign

The assistant should present confirmation for destructive/high-impact actions.

## 12. Design System
Use:
- generous whitespace
- rounded cards
- subtle elevation
- clear typography hierarchy
- accessible contrast
- responsive layouts
- consistent status chips
- elegant AI indicators

Avoid:
- overly colorful dashboards
- excessive gradients
- dense tables
- generic Bootstrap admin appearance

## 13. States
Every screen must have:
- loading
- empty
- error
- success
- permission denied
- no connected account
- generation in progress

## 14. Mobile
Mobile should support:
- reviewing content
- approving
- rescheduling
- checking publishing status
- analytics summary
- AI assistant

Full creative editing can remain desktop-first.
