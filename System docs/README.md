# AI Marketing Employee

Production-oriented MVP blueprint for an AI-native marketing SaaS.

## Start Here
1. Read `01-PRD.md`
2. Read `02-ARCHITECTURE.md`
3. Give `08-IMPLEMENTATION-PLAN.md` to Antigravity.
4. Implement one phase at a time.
5. Use `05-SOCIAL-PUBLISHING.md` before implementing OAuth/publishing.
6. Use `04-AI-ARCHITECTURE.md` before implementing Gemini agents/tools.

## Product Flow
Brand Brain → Strategy → Content → Creative → Calendar → Publishing → Analytics → Optimization.

## Important
External social APIs and Google AI capabilities change over time. Verify current official documentation, scopes, quotas, review requirements, and pricing before production rollout.
